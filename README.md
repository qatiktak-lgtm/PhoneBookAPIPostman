# PhoneBook API Postman Collection

Коллекция запросов и автоматизированных тестов для тестирования **PhoneBook API**, собранная и настроенная в Postman. Проект предназначен для демонстрации навыков API-тестирования, работы с Postman, написания тестов на JavaScript (Chai/Postman Sandbox) и автоматизации.

---

## 🛠 Технологический стек
* **Инструменты:** Postman, Newman (для запуска из CLI)
* **Языки скриптов:** JavaScript (для написания тест-кейсов и валидации ответов)
* **Форматы:** JSON (Postman Collection v2.1, Environment)
